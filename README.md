# علی زندیه، پروژه تحلیل اکتشافی دیتاست اخبار فارسی

این پروژه برای انجام موارد خواسته‌شده در فایل مصاحبه طراحی شده است: بررسی ساختار و کیفیت داده، آمار دسته‌ها/منابع/زمان، پردازش مقدماتی متن فارسی، ۲۰ واژه پرتکرار، مقایسه واژگان دسته‌ها، حداقل سه نمودار و گزارش یافته‌ها.

## ساختار پروژه

```text
persian_news_analysis/
├── analyze_news.py
├── config.json
├── requirements.txt
├── README.md
├── data/                 # فایل دیتاست را اینجا قرار دهید
└── outputs/              # خروجی‌ها بعد از اجرا ساخته می‌شوند
```

## خروجی‌ها

پوشه `outputs/` در زمان اجرا ساخته می‌شود و شامل موارد زیر است:

- `data_quality.json`: تعداد ردیف/ستون، ستون‌های شناسایی‌شده، مقادیر گمشده و تکراری‌ها
- `column_profile.csv`: نوع داده، مقادیر یکتا و میزان داده ناقص هر ستون
- `category_statistics.csv`: تعداد و درصد اخبار هر دسته
- `source_statistics.csv`: تعداد و درصد اخبار هر منبع، در صورت وجود ستون منبع
- `monthly_statistics.csv`: توزیع ماهانه، اگر ستون تاریخ قابل‌تفسیر باشد
- `top_20_words.csv`: ۲۰ واژه پرتکرار پس از حذف stopwordها
- `text_statistics.json`: میانگین، میانه، حداقل و حداکثر تعداد واژه‌ها
- `category_top_words.csv`: واژه‌های پرتکرار برای چند دسته اول، در صورت وجود دسته‌بندی
- `cleaned_news.csv`: داده اصلی به‌همراه ستون‌های نرمال‌شده و شمارش واژه‌ها
- نمودارهای PNG
- `report_fa.md`: گزارش فارسی با یافته‌های مبتنی بر اجرای واقعی
- `output.rar`: فشرده‌ سازی تمام فایلها برای سابمیت روی گیت هاب
## تصمیم‌های فنی

- نگاشت حروف عربی/فارسی: `ي` و `ى` به `ی`، و `ك` به `ک`
- تبدیل ارقام فارسی/عربی به لاتین، حذف URL و علائم نگارشی، و یکسان‌سازی فاصله‌ها
- تشخیص ستون‌ها با نام‌های رایج فارسی و انگلیسی؛ ستون‌های شناسایی‌شده در گزارش ثبت می‌شوند
- آمارهای خروجی فقط پس از اجرای اسکریپت روی داده واقعی تولید می‌شوند؛ از پیش عددی ساخته نشده است
- هیچ مدل یادگیری ماشین یا تحلیل احساسات استفاده نمی‌شود
